# Malla Charmi Portfolio Website

## Overview

This is my personal portfolio website built to showcase my skills, projects, certifications, internship experience, and achievements in Data Analytics, AI & ML, Cloud Computing, and Frontend Development.

The portfolio features a modern responsive UI with animations, smooth scrolling, project showcases, and contact functionality.
